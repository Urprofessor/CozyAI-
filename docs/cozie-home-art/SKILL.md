# Cozie 的家：美术资产清单

## 你要做什么
为网页 demo 里的"Cozie 的家"出图。页面是一个**占满手机全屏的房间**，Cozie 在里面生活、走动、拿手机回消息。代码会把你交付的图**分层叠起来**，所以背景、角色、前景必须分开，并且严格对齐。

**风格 = 直接照抄 [`references/room-concept.png`](references/room-concept.png)**：同样的暖色 3D 阁楼、同样的家具和陈列、同样的材质（奶白毛绒、浅色原木、鼠尾草绿、豆沙粉）、同样的柔和暖光和镜头角度。不要重新设计房间，不要换风格。

## 全局规格
- **画布**：1290 × 2666 px（宽:高 = 300:620）。所有"整张画布"图层都用这个尺寸，同一个坐标系。
- **构图**：把概念图按宽度放大到 1290（高约 1935），顶边放在 y = 330。
  - **上方 0–330 px 补画**：斜屋顶和木梁继续往上延伸。这里会被顶栏 UI 盖住，不要放重要物件。
  - **下方约 2265–2666 px 补画**：木地板继续往下延伸。这里会被输入框盖住，只放地板。
  - 中间部分尽量和概念图一致。
- **左右各 4% 可能被裁掉**（不同手机比例），重要物件别贴边。
- **禁止**：背景里不能有 Cozie、不能有 Mila、不能有任何文字或 UI（按钮、对话框、输入框）、不能有水印。
- **格式**：PNG，sRGB。带透明的图层用 32 位 PNG，边缘干净、不要白边、不要棋盘格假透明。
- **一致性**：同一时段的所有图层必须光线、色调一致；叠在一起要像一张图。

## 三个时段
代码按真实时间切换三个时段。每个"整张画布"图层都按时段各出一张：
| 时段 | 文件后缀 | 光线 |
|---|---|---|
| 夜里 | `_night` | **就是概念图的光**：窗外蓝紫暮色，蘑菇灯和整体暖光（P0，最先做） |
| 下午 | `_afternoon` | 窗外晴天，柔和自然光从右侧窗户进来，蘑菇灯关或很弱（P0） |
| 早上 | `_morning` | 窗外清晨暖橙色，光线更低更暖（P1） |

### C. Cozie 角色
**外观照概念图里的 Cozie**：奶白偏暖、哑光微透的软胶质感，粉色只出现在腮红和耳朵内侧，深色亮眼睛，圆润身体，悬浮的长耳朵和椭圆小手。**不要粉色全身、不要高光塑料感**（现在旧动画的问题就是太粉太亮）。

**规格（每个姿势都一样）**
- 1024 × 1024 px，透明底。
- **脚底线固定**：角色身体最低点（不算影子）一律落在 **y = 880 px**，水平居中（x = 512）。
- **大小固定**：身体宽度（不算耳朵和手）约 **560 px**，各姿势之间比例一致，不能忽大忽小。
- **光**：主光是左上方暖光（蘑菇灯方向），右侧带一点窗户的轮廓光，和 A1 的夜里版一致。
- **不要画地面投影**，代码会加柔和的接触阴影。如果方便，另出一张 `cozie_shadow.png`（同画布、只有椭圆投影）。
- 角色正面或微侧，适合放在房间地面上；不要带背景、地面或道具以外的场景元素。

**先交静帧（P0），再交动画（P1）**。静帧命名 `cozie_{姿势}.png`；动画给 PNG 序列 `cozie_{姿势}/0000.png …`，24fps，2–4 秒，**首尾能无缝循环**，每帧都遵守上面的脚底线和大小。

| 姿势 | 页面里什么时候用 | 描述 | 参考 | 优先级 |
|---|---|---|---|---|
| `phone` | 回复用户消息时 | **概念图那个姿势**：双手捧着鼠尾草绿手机，低头看屏幕，微笑。动画：轻微呼吸、眨眼、手指点屏幕 | 概念图 | P0 |
| `idle` | 平时站着 | 放松站立，轻微呼吸、眨眼、耳朵轻晃 | `pose-neutral-sheet` | P0 |
| `listen` | 用户正在打字 | 耳朵竖起、身体微微转向镜头，像在认真听 | `pose-listening-sheet` | P0 |
| `think` | 等待回复生成 | 一只手托腮，头顶一个小思考云 | `pose-thinking-sheet` | P0 |
| `journal` | 平时自己做事 | 坐着在本子上写字 | `pose-journal-sheet` | P0 |
| `look` | 查看书架、便签板、日历 | 拿放大镜看，或凑近看 | `pose-discovery-sheet` | P0 |
| `empathy` | 用户说累、难过 | 双手抱着一颗粉色爱心 | `pose-empathy-sheet` | P0 |
| `happy` | 普通开心回应 | 开心地小蹦一下 | `pose-happy-sheet` | P1 |
| `celebrate` | 好消息、里程碑 | 撒少量彩纸（彩纸颜色用房间色系） | `pose-celebrate-sheet` | P1 |
| `encourage` | 感谢、鼓励 | 捧着一小束花 | `pose-encourage-sheet` | P1 |
| `stars` | 推荐东西 | 挥小魔法棒，带几颗小星星 | `pose-stars-sheet` | P1 |
| `sit` | 坐在单人沙发上休息 | 坐姿，适合放在沙发座面上 | — | P1 |
| `tend` | 在婴儿床边照顾 Mila | 微微前倾、手伸向前方，温柔的表情 | — | P1 |
| `fold` | 平时自己做事 | 坐在地毯上叠小衣服 | 概念图地毯上的衣服 | P2 |

**过渡动画（P1）**：
- `phone_up`：从 `idle` 拿起手机变成 `phone`，6–10 帧。
- `phone_down`：从 `phone` 放下手机回到 `idle`，6–10 帧。
- `hop`：原地小跳一下，8 帧，用来表现走路（代码负责平移）。

## 吸奶器的规则
- 外形严格按 `pump-reference.png`：两台并排、豆沙粉、圆润蛋形机身、顶部圆形小显示区、下部透明集奶杯。**不要**画成长奶瓶或传统喇叭口造型。
- 机身上的品牌字样只能照实物图的位置和样式。看不清就不画，不要编造字样。
- 它是房间里的生活用品，安静地放在沙发边小凳上，不加发光、标签或任何广告感的强调。

## 交付前自检
1. **对齐**：按 A1 → A4 → Cozie（站在 `layout-guide.png` 的任一站位点）→ A2 → A3 的顺序叠起来，导出 `preview/composite_*.png`。看起来要像一张完整的概念图，没有错位和接缝。
2. **干净**：背景里没有角色、没有文字和 UI；透明图层边缘没有白边。
3. **角色一致**：把所有 Cozie 静帧叠在一起，脚底线都在 y = 880，大小一致，颜色是奶白不是粉色。
4. **安全区**：顶部 330 px、底部约 400 px、左右各 4% 里没有关键物件。
5. **产品**：吸奶器和实物图对得上。

## 不要做的事
- 不要换风格，不要"改良"概念图的房间布局。
- 不要把聊天框、按钮、文字烘焙进任何图。
- 不要把 Cozie 画成人类妈妈，或改变 IP 的基本结构。
- 不要给宝宝或角色加真实的医疗场景、药品。
- 不要额外做多房间、商城、货币等没要求的东西。

## 给接入方（写代码的那一方）
- 素材放到 `public/cozie/home/room/`、`public/cozie/home/cozie/` 等目录。

- 角色动画转成动图 WebP（约 320–400 px、12fps），并按"脚底线 y = 880/1024"设置锚点。
