# Cozie 的家：换风格指南

## 这份文档解决什么
"Cozie 的家"已经是一个能运行的页面：全屏小屋、Cozie 在房间里生活和发消息、胎教作画、胎教作曲、万圣节装扮。现在用的是一套暖色软陶 3D 风格。

如果公司要换风格，**功能和代码不用动**，只需要美术按这份文档：
1. **先定义新风格**：填好第一部分的"风格定义表"，出两张样张，评审通过。
2. **再批量出图**：按第二部分的**固定技术规格**和第三部分的**交付清单**出全部资产，文件名和现在一一对应。
3. **工程替换**：直接替换文件，再微调少量坐标（主要是房间布局变了的话）。

> 这份文档只管"要准备什么、按什么规格交"。具体选什么风格，由公司和美术负责人决定。

## 第一部分：先定义新风格（必须先拍板）

### 1.1 风格定义表（请美术负责人填写后附在交付包里）
| 项目 | 需要回答的问题 | 现有风格（参考） |
|---|---|---|
| **渲染方式** | 3D 软陶 / 2D 手绘插画 / 扁平矢量 / 水彩 / 其他？是否有描边？ | 3D 软陶，无描边，柔和体积和投影 |
| **整体气质** | 三个关键词 | 温暖、治愈、像玩具 |
| **色板** | 主色、辅色、强调色、中性色，各给色值；哪种颜色只用在操作上 | 奶白、浅原木、鼠尾草绿、豆沙粉；强调色酒红 `#770523` |
| **光线** | 光源方向；早上、下午、夜里三个时段各是什么光 | 左上暖光；夜里蘑菇灯暖光 + 窗外暮色 |
| **材质与纹理** | 家具、布料、纸面怎么表现？有没有颗粒、笔触、纸纹？ | 软陶、毛绒、浅木纹、淡纸纹 |
| **房间** | 还是阁楼婴儿房吗？视角（正面/俯视/等距）？家具清单是否变化？ | 斜屋顶阁楼，正面略俯视 |
| **Cozie 的表现** | 在新风格里怎么画 Cozie（见 1.2，IP 结构不能变） | 奶白哑光软胶，粉腮红 |
| **UI 元素语言** | 按钮、卡片、相框、图钉这类元素的形状、厚度、状态怎么区分 | 软陶圆片、浅浮雕图标，选中时微隆起或细环 |
| **动画风格** | 帧率、弹性大不大、是逐帧还是骨骼 | 24fps 逐帧，2–4 秒循环 |
| **品牌约束** | 是否遵守 Momcozy 3.0：品牌色只用于操作和强调，**不铺满整页粉色** | 遵守 |

### 1.2 不能变的东西（换风格也要保留）
- **Cozie 的 IP 结构**：圆润的单体身体、**悬浮的长耳朵**、**悬浮的椭圆小手**、深色眼睛、腮红。不要画成人类妈妈，不要加嘴以外的五官变化，不要改变比例到认不出来。IP 原形见 `../references/cozie-ip.png`。
- **Mila**：Cozie 的宝宝，同一 IP 的缩小版，只露头和耳朵趴在婴儿床里。
- **产品外观必须和实物一致**：
  - Momcozy 穿戴式吸奶器：一对、圆润蛋形机身、顶部圆形显示区、下部透明集奶杯（`../references/pump-reference.png`）。
  - 胎教仪：圆润卵石形机身、顶部深色圆形区和白色波浪标志、一条深色细带延伸到边缘，**未激活 / 已激活（圆形区外圈亮青蓝色光环）**两态。
  - 产品上的品牌字样只能照实物位置和样式；看不清就不画，不要编造。
- **图里不要有任何文字**（极少数例外见各清单，比如 Cozie 签名章里的 "Cozie"）。所有中文由代码渲染。
- **6 个画笔颜色和 5 个音符颜色**是功能色（选什么色就画出什么色、颜色区分音高），色块的平均色要和新色板里定的值一致。

### 1.3 先交两张样张，评审通过后再批量
1. **主场景样张**：下午时段的完整房间（按第二部分的画布规格），里面放上 Cozie（拿手机的姿势）、Mila、婴儿床、吸奶器或胎教仪。
2. **UI 套件样张**：一张图里摆出：一个按钮的常态 / 选中 / 禁用三态、一个颜色选择、一个音符、一个相框、一个图钉、作画和作曲两个入口按键。

评审重点：和品牌是否一致、Cozie 是否认得出、文字（代码渲染的深色字和毛玻璃气泡）放上去是否看得清、三个时段能否保持同一套风格。

## 第二部分：固定技术规格（换风格也必须遵守）

这些规格是代码已经依赖的。**改了就需要改代码**，如确需改动，先和工程确认。

### 2.1 房间画布
- **画布 872 × 1802 px**（宽:高 = 300:620，覆盖手机全屏）。所有"整张画布"图层都用这个尺寸、同一坐标系、像素对齐。
- **安全区**：顶部约 12% 是顶栏（标题和按钮）；底部约 10% 是输入框；左右各约 4% 在部分手机上会被裁掉。这些区域只放墙面、天花板或地板，不放可点的物件。
- **三个时段**：`morning`、`afternoon`、`night`。每个整张画布图层都要三张，构图完全一致，只是光线不同。
- **图层顺序**（从后到前）：背景 → 床铃支架和挂件 → 万圣节装饰 → 胎教仪 / 墙上的画 → Mila → 婴儿床正面栏杆 → 可点区域 → Cozie → 前景（绿植、坐墩）→ 气泡和界面。**会被角色挡住或要挡住角色的东西必须拆成独立图层**（例如婴儿床正面栏杆）。
- **可点的物件**（书架、便签板/画板、日历、窗台、婴儿床、吸奶器小凳、胎教仪、床铃）要画得清楚可辨，周围留出 Cozie 能站的地面。如果房间布局变了，请随样张附一张**物件位置标注图**（每个物件的大致矩形框），工程据此重新校准坐标。

### 2.2 角色动画
- 每帧 **1024 × 1024 px 透明 PNG**，角色水平居中（x = 512），**身体最低点固定在 y = 880**，身体宽度（不含耳朵和手）约 **560 px**，所有动作比例一致。
- **24fps，2–4 秒，首尾无缝循环**；过渡动作 6–10 帧。
- 不要画地面投影（代码会加）。
- 光线和房间下午时段一致即可（代码会给夜里整体压暗）。

### 2.3 UI 元素
- **@3x 透明 PNG**，尺寸见 [`ASSET_INVENTORY.md`](ASSET_INVENTORY.md)，比例必须一致。
- **状态命名**：常态不加后缀；选中/按下 `_on`；禁用 `_off`。
- **相框类**（墙上小画框、画作墙卡片、大图画框）：标注"放画的窗口"在图里的位置（左、上、右、下的百分比），代码会把画放进这个窗口。
- 画纸外框：**中间必须真透明**（用户在下面作画）。

### 2.4 交付格式
- PNG（工程会转 WebP），sRGB，透明图层边缘干净，不要白边，不要棋盘格假透明。
- **文件夹结构和文件名照 `ASSET_INVENTORY.md`**（`room/`、`anim/`、`device/`、`drawing/`、`compose/`、`halloween/`）。动画给 PNG 序列文件夹：`anim/c_<动作>/0000.png …`。

- 声音：作曲的音色由代码实时合成，不需要音频素材。

## 第五部分：交付与验收

### 交付包结构
```
cozie-home-art-<风格名>/
  STYLE.md          ← 第一部分的风格定义表（填好）
  LAYOUT.png        ← 物件位置标注图（房间布局有变化时必交）
  room/  anim/  device/  drawing/  compose/  halloween/
  preview/          ← 自检合成图
  ANCHORS.md        ← 床铃锚点、相框窗口、五线谱线位置等坐标
```

### 自检清单
1. **合成预览**：按图层顺序叠出三个时段的完整房间（含 Cozie 和 Mila），各一张；作画页、作曲页各一张。
2. **对齐**：同一时段的所有整张画布图层像素对齐，叠起来没有错位和接缝。
3. **角色一致**：把所有动作的第一帧叠在一起，脚底线都在 y = 880，大小一致，颜色一致。
4. **认得出 Cozie**：给不了解项目的人看，能认出是同一个 IP。
5. **产品准确**：吸奶器、胎教仪和实物图对得上。
6. **可读性**：深色文字、毛玻璃气泡放在墙面上看得清；顶部 12%、底部 10% 没有关键物件。
7. **功能色**：6 个画笔色、5 个音符色和色板一致，能一眼区分。
8. **无文字**：除明确允许的地方外，图里没有文字和水印。
9. **命名和尺寸**：文件名、比例、透明与否和 `ASSET_INVENTORY.md` 一致。

### 工程接入（给工程看）
- 文件直接替换 `public/cozie/home/` 下的同名文件（PNG 转 WebP；动画序列用现有脚本切成 320px、12fps 的动图 WebP，并统一身体大小和脚底线）。
- 房间布局有变化时，按 `LAYOUT.png` 更新 `lib/cozy/home/scene.ts` 里的物件、站位、Mila、婴儿床栏杆、床铃、胎教仪坐标；按 `ANCHORS.md` 更新相框窗口（`DRAW_ART`）和五线谱线位置（`STAFF`）。
- 新增的产品图层（吸奶器单独一层）接入后，背景里不再画吸奶器，绑定设备切换时只显示对应产品。
